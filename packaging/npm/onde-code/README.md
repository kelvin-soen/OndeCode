# Onde Code

Onde Code is Onde Inference's ACP-compatible coding agent for model fine-tuning and deployment.

## Install

```sh
npm install -g @ondeinference/onde-code
```

npm pulls in the right binary for your platform automatically.

To use it from an ACP editor without a global install:

```sh
npx @ondeinference/onde-code --acp
```
